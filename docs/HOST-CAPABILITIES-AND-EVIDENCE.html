Host capabilities and evidence boundaries

Officecraft governs the job. The active host creates, edits, renders, exports, or connects only when that capability is actually present and applicable in the current run.

Do not collapse these states

State What it means What it does not mean
Available A package, tool, app, or connector can be selected in this host. It fits this job or has been used.
Applicable The available route preserves the artifact properties this job needs. It created the artifact.
Executed The route was used on this job. The result was visually or natively inspected.
Inspected A named check ran on the resulting artifact. Every quality or accessibility property is proven.
Native-verified A connected native surface confirmed the relevant result. The artifact is approved or externally delivered.

Capability routes

Need Preferred route when observed Honest fallback
New editable document, deck, or workbook An active compatible artifact-production route with a writable output path. A complete source-ready production packet.
Existing cloud-native file or template Its connected native surface with target and account confirmed. Preserve the original and write a safe adaptation plan.
Visual quality A renderer, export view, or opened native view. Structural review with visual inspection explicitly pending.
Workbook calculation An active compatible workbook surface. Formula and data-lineage audit, with recalculation pending.
Branded deck An authorized template or connected design surface. Slide map and visual specification pending native build.

Current build-host observations

The build host was observed to expose dedicated document, presentation, spreadsheet, PDF, live workbook-control, Google Workspace, and branded-presentation capability packages. It also had local desktop Office registrations and local document/PDF libraries available for possible routing.

Those are route-discovery observations, not release-wide guarantees. No live Google, Canva, or Excel session was observed. No fresh Codex or Claude host was used to establish discovery or activation. No native Office automation was performed. LibreOffice was not available on that host.

Bundled host skills are dependencies, not release contents

Some hosts provide bundled OpenAI office skills. Officecraft may call an applicable active host capability, but this release does not copy, distribute, or derive from those bundled skills. A supplied Officecraft skill remains useful without them because it can preserve the brief, content spine, format specification, quality checklist, and handoff for a later compatible route.

When a route is missing

Keep working on the part that remains possible: settle the brief, source custody, content ledger, artifact specification, and quality plan. State the missing route, affected artifact, assurance lost, current status, and exact re-entry condition. Do not call a fallback file-produced, visually inspected, recalculated, imported, or natively verified unless that event occurred.

For recovery steps, see Troubleshooting and recovery.
