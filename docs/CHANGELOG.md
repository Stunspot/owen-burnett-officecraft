# Changelog

## v0.1.0 - 2026-07-21

Initial Owen Burnett Officecraft package version.

- Added the `owen-burnett-officecraft` operator for office-production intake, one-content-spine coordination, artifact routing, Officefile state, bounded inspection, recovery, and handoff.
- Added the independent `officecraft-reviewer` for evidence-bounded review dispositions.
- Added portable Officefile templates, schemas, standard-library scripts, and a fictional shaped example.
- Added separate Codex and Claude distribution guidance, host-capability boundaries, troubleshooting, provenance, and readiness documentation.

Known boundaries at this version: no claim of fresh-host activation, native Office automation, cloud connection, publication, external delivery, or representative-user validation. See [Verification and readiness](VERIFICATION-AND-READINESS.md).
