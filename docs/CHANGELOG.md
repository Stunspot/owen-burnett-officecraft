# Changelog

## v0.1.0 - 2026-07-24

First free public Owen Burnett Officecraft release under the MIT License.

- Added the `owen-burnett-officecraft` operator for office-production intake, one-content-spine coordination, artifact routing, Officefile state, bounded inspection, recovery, and handoff.
- Added the independent `officecraft-reviewer` for evidence-bounded review dispositions.
- Added portable Officefile templates, schemas, standard-library scripts, and a fictional shaped example.
- Added separate Codex and Claude distributions, host-capability boundaries, troubleshooting, provenance, and readiness documentation.
- Published a fresh public history without private development records, canonical persona source copies, workstation paths, or host-private evaluation traces.

Known boundaries at this version: no broad claim of fresh-host activation, native Office automation, cloud connection, external delivery, formal accessibility conformance, or representative-user validation. See [Verification and readiness](VERIFICATION-AND-READINESS.md).
