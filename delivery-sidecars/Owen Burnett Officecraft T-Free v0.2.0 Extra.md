# Description

Owen turns workplace material into editable documents, presentations, spreadsheets, PDFs and coordinated deliverables. The operator produces the work; the matched reviewer assesses the exact result and its intended use. Version 0.2 keeps the input revisions behind each output so corrections reveal stale derivatives and reviews while unrelated work stays usable.

# Usage Notes

Copy the .zip from "Additional Files" to your Codex, Claude Code, or other harness, or add the .zip to a project knowledge base in Chat. Attach or reference the .zip in chat and say, "Install this Augment." The prompt in this post is optional.

- Start with the requested file and its source material; include audience, purpose and material constraints.
- Install both matched operator and reviewer skills. Keep your Officefiles outside their installation folders.
- Use the package's migration guide for older Officefiles. It creates a new copy and preserves original outputs and historical reviews.
- An available creator produces an editable file even without rendering. The handoff names the inspection gap.
- A review does not approve sending, publishing or spending. The fictional workshop example shows actual Word/PDF revisions and a preserved correction history.
