# Start here

1. Read the maintained [orientation](source/owen-burnett-officecraft-v0.1.1/README.md) and [installation guide](source/owen-burnett-officecraft-v0.1.1/START-HERE.md).
2. Install both folders under `codex/`, or both untouched archives under `claude/`.
3. Restart the host, confirm discovery, invoke Owen explicitly, and run a small low-risk job.
4. Keep operator and reviewer on the same version. Do not install source, manifests, or checksums as runtime cargo.
