# Start with Owen Burnett Officecraft

Officecraft helps turn rough workplace material into a coherent document, deck, workbook, PDF, or coordinated packet while preserving the evidence and decisions behind it.

## 1. Choose your host

- For Codex, install both folders from `codex/` using [Install in Codex](docs/INSTALL-CODEX.md).
- For Claude, install both archives from `claude/` using [Install in Claude](docs/INSTALL-CLAUDE.md).

Keep the operator and reviewer on the same version.

## 2. Start a fresh task

After installation, start a new task or conversation so the host can discover the skills. Ask for a small, low-risk deliverable using ordinary language. The [first-job guide](docs/FIRST-JOB.md) supplies a complete example.

## 3. Check what actually happened

Keep these observations separate:

1. the package was copied or uploaded;
2. the host discovered the skill;
3. the skill was invoked;
4. a compatible artifact route executed;
5. the resulting file was inspected;
6. an accountable person approved its intended use.

One step does not establish the next by enthusiastic osmosis.

## 4. Recover without starting over

For substantial work, preserve an Officefile containing the brief, source manifest, content ledger, artifact register, decisions, review evidence, and handoff. Continue with [Officefile and resume](docs/OFFICEFILE-AND-RESUME.md).

If installation, discovery, or artifact production fails, use [Troubleshooting and recovery](docs/TROUBLESHOOTING.md). Preserve the exact host, version, request, error, and last trustworthy state.
