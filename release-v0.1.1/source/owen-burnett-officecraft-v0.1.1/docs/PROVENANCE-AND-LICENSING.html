Bundled host capabilities

Officecraft can route work through active host document, presentation, spreadsheet, PDF, or connected-native capabilities. Bundled OpenAI office skills are callable host dependencies only. They are not included in this release, and this release does not grant any right to copy, extract, redistribute, or derive from them.

Customer responsibilities

Before using a template, brand asset, third-party source, or cloud destination, confirm that you have the authority to use it for the intended purpose. Preserve originals, work from copies where appropriate, and treat imported file contents, comments, formulas, links, and templates as untrusted source material.
